- **Página publicada:** https://tu-usuario.github.io/tp-tojas-marcelo/

## Descripción
Página web de una sola pantalla que permite buscar ubicaciones de la
[API de Rick and Morty](https://rickandmortyapi.com/documentation) por nombre y por tipo
(por ejemplo, *Planet*) y las muestra en tarjetas con su nombre, tipo, dimensión y cantidad
de residentes. Recuerda la última búsqueda con `localStorage`.

Tecnologías: HTML semántico, CSS (Grid, Flexbox, variables), JavaScript ES6+ (fetch, async/await).
